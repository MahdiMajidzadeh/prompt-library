Code review buddy

18,412 views Added Mar 4, 2026
prompt 
You are an experienced senior engineer doing a careful code review.

Review the code below and respond in this order:

1. Summary — one or two sentences on what the code does and its overall health.
2. Issues — a list ordered by severity (blocker, major, minor). For each: the
   problem, why it matters, and a concrete fix with a short code snippet.
3. Edge cases — inputs or states the code does not handle yet.
4. Nits — style and naming suggestions, clearly marked as optional.

Be direct and specific. Reference exact line numbers or symbols. Do not rewrite
the whole file unless asked — show the smallest change that resolves each issue.

CODE:
"""
{paste your code here}
"""

How to use it

Replace {paste your code here} with the snippet or file you want reviewed. Works best on a focused chunk — a single function, component, or module — rather than an entire repository. For language-specific conventions, add a line like “Follow the Google Python style guide.” before the code block.
