Prompt Library Design System v1

Design System

Prompt Library

A calm, editorial, content-first system for browsing and copying AI prompts. Near-monochrome by design, with one restrained accent and a clear split between UI chrome (sans) and literal prompt text (monospace). Try the accent swatches and dark-mode toggle above — every component reacts live.

01 — Foundations

Typography

Geist for UI and headings; Geist Mono for prompt text, code, counts, and metadata. The monospace is deliberate — it signals "this is the literal, copyable machine text," visually distinct from the chrome around it.

02 — Foundations

Color

Near-monochrome: a warm off-white ground, near-black text, muted grays, and hairline borders. All neutrals are theme-aware tokens, so the same component renders correctly in light and dark. Text on background meets WCAG AA.

Neutral tokens — current theme

Accent — pick the default (applies live)

One accent only — links, the copy button, active tags, and focus rings. Everything else stays neutral. Swap it here or from the top bar; the whole system follows.
